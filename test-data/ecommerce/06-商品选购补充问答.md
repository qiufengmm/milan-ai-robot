# 米兰数码商城 · 商品选购补充问答

本文件为演示数据补充。商品型号、参数和价格均为虚构，仅用于知识库检索演示；不代表真实商品或实时库存。

## 耳机 · AirBuds Pro 2 与 LiteBuds S 怎么选

**常见问法**：AirBuds 和 LiteBuds 有什么区别 / 便宜的耳机有降噪吗 / 哪款能无线充

**答案**：AirBuds Pro 2 售价 499 元，入耳式，支持最高 42dB 主动降噪、Qi 无线充电和双设备连接；LiteBuds S 售价 199 元，是半入耳式，不支持主动降噪和无线充电，仅支持通话降噪。预算优先选 LiteBuds，通勤降噪选 AirBuds。

## 耳机 · StudioMax 70 的有线连接

**常见问法**：StudioMax 70 能插线吗 / 头戴耳机没蓝牙还能接电脑吗 / 有 3.5mm 接口吗

**答案**：StudioMax 70 提供 3.5mm 有线接口，除蓝牙 5.2 外也可通过有线方式连接带 3.5mm 音频口的设备。商品参数只确认耳机有该接口，不代表包装一定附带音频线；具体包装清单以商品页为准。

## 耳机 · IPX4 防护能否游泳或冲洗

**常见问法**：IPX4 可以游泳吗 / 耳机能不能水洗 / 出汗后能直接冲水吗

**答案**：AirBuds Pro 2 与 LiteBuds S 的 IPX4 适合应对日常汗水和少量飞溅，不代表可以游泳、淋浴、浸泡或用水冲洗。使用后建议擦干表面；进液不属于免费保修范围。

## 键盘 · K87 Pro 三模与同时连接设备

**常见问法**：三模键盘能同时连三台电脑吗 / K87 Pro 怎么切蓝牙和 2.4G

**答案**：K87 Pro 的“三模”指蓝牙 5.1、2.4G 接收器和 Type-C 有线三种连接方式，可通过键盘开关切换；它不表示三种方式同时连接，也不表示能同时输入到三台设备。2.4G 模式需要插入接收器。

## 键盘 · K87 Pro 热插拔轴体兼容性

**常见问法**：K87 Pro 能自己换轴吗 / 支持几脚轴 / 红轴可以拔下来换吗

**答案**：K87 Pro 支持热插拔轴体，兼容 3 脚和 5 脚轴，原配可选红轴、茶轴或青轴。更换前应断开键盘连接并确认新轴体规格；热插拔不代表键帽、定位板或所有键盘配件都通用。

## 键盘 · K104 是机械键盘还是薄膜键盘

**常见问法**：K104 有机械轴吗 / 104 键带小键盘吗 / K104 能连蓝牙吗

**答案**：K104 是 104 键静音薄膜键盘，不是机械键盘，带独立数字小键盘；只支持 USB-A 有线连接，不支持蓝牙、无线、热插拔或驱动改键。它适合需要全尺寸布局和简单办公输入的场景。

## 键盘 · K68 磁轴是否无线及高回报率条件

**常见问法**：K68 磁轴能无线用吗 / 8000Hz 插普通接口可以吗 / K68 触发距离可调吗

**答案**：K68 仅支持 Type-C 有线连接，不支持蓝牙或 2.4G。触发行程可在 0.1 至 4.0mm 调节；最高 8000Hz 需要接口和线材都支持相应回报率，达不到条件时不应承诺能跑满 8000Hz。

## 鼠标 · M5 与 M9 Pro 的定位区别

**常见问法**：M5 和 M9 Pro 哪个适合办公 / 哪个能蓝牙 / 电竞鼠标怎么选

**答案**：M5 是静音办公鼠标，支持 2.4G 与蓝牙 5.0、最高 4000 DPI，使用一节 AA 电池；M9 Pro 面向游戏，最高 26000 DPI、约 58 克，支持有线和 2.4G，但不支持蓝牙。需要蓝牙选 M5，需要高 DPI 或宏设置可看 M9 Pro。

## 充电器 · GaN 65W 与 GaN 100W 怎么选

**常见问法**：65W 和 100W 充电器差多少 / 四个口是不是每个都有 100W / 多设备怎么选

**答案**：GaN 65W 有 2 个 USB-C 和 1 个 USB-A，总功率不超过 65W；GaN 100W 有 3 个 USB-C 和 1 个 USB-A，总功率不超过 100W。100W 款接口更多、单口上限更高，但多设备同时充电时会分配总功率，设备与线材也需支持对应协议。

## 充电宝 · 标称容量与实际可用容量

**常见问法**：一万毫安为什么只能充一次 / 额定容量是什么意思 / 磁吸充电宝有线多快

**答案**：磁吸无线充电宝标称 10000mAh 是电芯容量，额定输出容量为 6000mAh；受电压转换和能量损耗影响，实际约可给手机充 1.2 至 1.5 次。无线最高 15W，有线 USB-C 最高 20W PD，实际速度还取决于手机和线材。

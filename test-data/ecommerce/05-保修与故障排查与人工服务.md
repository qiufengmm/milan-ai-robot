# 米兰数码商城 · 保修、故障排查与人工服务知识库

本文件为演示数据。文中保修期限、寄修规则与客服联系方式均为虚构，仅用于知识库检索演示。

---

## 保修 · 各类商品保修期

**常见问法**：保修多久 / 耳机保修几年 / 键盘保修期 / 充电器有保修吗 / 电池保修吗

**答案**：各类商品保修期：

- 耳机（AirBuds Pro 2、StudioMax 70、LiteBuds S）：主机 12 个月，充电盒 12 个月
- 键盘（K87 Pro、K104、K68）：主机 12 个月
- 鼠标（M5、M9 Pro）：主机 12 个月
- 充电器（GaN 65W、GaN 100W）：主机 12 个月
- 磁吸无线充电宝：主机 12 个月，电池容量衰减超过 20% 可申请检测
- 通用配件（充电线、耳帽、接收器、键帽）：3 个月

保修期自签收之日起计算，非按开票日期或下单日期计算。

## 保修 · 保修需要什么凭证

**常见问法**：保修要发票吗 / 没发票能保修吗 / 保修卡丢了 / 怎么证明在保修期

**答案**：保修凭证规则：

- 凭订单号即可保修，无需提供发票、保修卡或包装盒。
- 商城按订单签收时间自动计算保修期，售后系统可核查。
- 二手转赠的商品同样按原订单签收时间计算保修期，不重新起算。
- 无法提供订单号时，需提供购买时使用的手机号，由人工客服协助核查。

发票仅用于报销，不影响保修权益。

## 保修 · 哪些情况不在保修范围

**常见问法**：进水了保修吗 / 摔坏了能保修吗 / 自己拆过还能保吗 / 保修免费吗

**答案**：以下情况不属于免费保修范围：

- 人为损坏：跌落、挤压、摔碰导致的外观破损或功能失效
- 进液、进水、受潮、腐蚀
- 私自拆机、擅自改装、非官方维修点维修过
- 使用非原装或不匹配的充电器导致烧毁
- 正常使用产生的外观磨损、掉漆、键帽打油
- 超出保修期

上述情况可付费维修，是否可修及报价需寄回检测后确认。

## 保修 · 寄修流程与运费

**常见问法**：怎么保修 / 寄回去修要多久 / 维修运费谁出 / 能上门维修吗

**答案**：寄修流程：

- 第一步：在「我的订单」中提交维修申请，说明故障现象。
- 第二步：售后审核通过后提供寄回地址，按提示寄回商品，建议保留寄件单号。
- 第三步：仓库收货检测，1 至 3 个工作日出检测结果。
- 第四步：确认属于保修范围的免费维修，维修完成后寄回，全程约 7 至 15 个工作日。

运费规则：保修期内质量问题，往返运费由商城承担；非保修范围或检测无故障的，往返运费由买家承担。

商城不提供上门维修服务，也不提供备用机。

## 排查 · 耳机连不上或单边没声音

**常见问法**：耳机连不上手机 / 只有一边有声音 / 搜不到蓝牙 / 老是断连

**答案**：按以下顺序排查：

- 电量：将两只耳机放回充电盒，确认指示灯亮起，充电 10 分钟后再试。
- 重置：两只耳机放回盒内，开盖状态下长按充电盒按键 10 秒至指示灯快闪，恢复出厂设置。
- 重新配对：在手机蓝牙列表中删除原配对记录，关闭再打开蓝牙，重新搜索连接。
- 单边无声：可能是耳帽堵塞或触点氧化，用干棉签清理出音孔与充电触点后重试。
- 双设备连接冲突：AirBuds Pro 2 支持双设备连接，若另一台设备正在播放，可能抢占音频，请暂停另一台设备。

以上均无效且购买未满 12 个月，可提交维修申请。是否属于质量问题以检测结果为准。

## 排查 · 键盘无响应或连不上

**常见问法**：键盘打不出字 / 无线连不上 / 键盘失灵 / 按键重复

**答案**：按键盘类型分别排查：

- K87 Pro（三模）：检查侧面模式开关是否在对应档位（蓝牙、2.4G、有线）；2.4G 需插好接收器；蓝牙需在系统中删除旧配对后重新配对；无线无响应先接 Type-C 有线测试，判断是电池还是无线模块问题。
- K104（有线）：更换 USB 接口，优先使用主板后置接口；确认线材完好。
- K68（有线磁轴）：确认使用支持 8000Hz 的接口与线材；用官方驱动检查触发行程设置是否被误调至极端值。
- 单键失灵：热插拔型号可尝试更换同规格轴体测试。

有线模式可用而无线不可用，通常与电量或配对有关；有线模式也不可用，需申请检测。

## 排查 · 鼠标不动或光标跳动

**常见问法**：鼠标没反应 / 光标乱跳 / 连不上电脑 / DPI 怎么调

**答案**：排查顺序：

- M5（双模）：更换一节新的 AA 电池；按底部按键切换 2.4G 与蓝牙模式；重新插拔接收器或删除蓝牙配对后重连。
- M9 Pro（有线与 2.4G）：先用有线模式测试，若能正常使用说明是无线接收问题，可更换 USB 接口或重新对码。
- 光标跳动：更换鼠标垫，避免在玻璃、镜面、深色反光桌面使用；清洁底部光学传感器窗口。
- DPI 异常：通过驱动或 DPI 按键恢复默认档位。
- 系统层面：在系统设置中确认指针速度未被调到极端值。

有线可用而无线不可用，多为接收器或电池问题；两种模式都不可用需申请检测。

## 排查 · 充电器不充电或发热明显

**常见问法**：充电器充不进电 / 充电很烫 / 充电速度慢 / 能充笔记本吗

**答案**：排查顺序：

- 确认线材支持对应功率：65W 与 100W 快充需使用支持 PD 的 C to C 线，普通 A to C 线无法触发高功率。
- 确认设备协议：设备需支持 PD 或 PPS 才能触发快充，不支持协议的设备只能普通速度充电。
- 更换插座与设备交叉测试，判断是充电器还是设备问题。
- 多口同时使用会按总功率智能分配，单口速度下降属于正常现象。
- 发热：高功率输出时外壳温热属正常，若烫手、有异味、外壳变形，立即停止使用并申请检测。

GaN 65W 单口最大 65W、GaN 100W 单口最大 100W，是否能为某款笔记本满速供电取决于该笔记本的充电协议与功率需求。

## 排查 · 充电宝充电慢或容量不足

**常见问法**：充电宝充得很慢 / 10000mAh 只能充一次 / 无线充电发热 / 能上飞机吗

**答案**：

- 容量：标称 10000mAh 为电芯容量，额定容量 6000mAh 才是实际可输出容量，扣除转换损耗后可为手机充电约 1.2 至 1.5 次，属正常现象。
- 无线充电慢：磁吸无线最高 15W，且手机需支持无线充电与磁吸对位；手机壳过厚或位置偏移会明显降速。
- 有线充电：需使用支持 PD 的线材才能达到 20W。
- 发热：无线充电时发热属正常，若明显烫手请取下手机壳或改用有线充电。
- 登机：额定能量约 37Wh，符合民航随身携带规定，可随身登机，不可托运。

若充电宝无法输出、指示灯异常，且在 12 个月保修期内，可提交维修申请。

## 人工服务 · 客服联系方式与时间

**常见问法**：人工客服电话多少 / 怎么联系人工 / 客服几点下班 / 有微信客服吗

**答案**：米兰数码商城的有效服务渠道只有以下两个：

- 在线人工客服：商城网页与 App 右下角「联系客服」入口，服务时间每日 9:00 至 21:00。
- 客服邮箱：support@milan-digital.example.com，用于提交图片、视频等凭证，非工作时间留言会在下一个服务时段回复。

商城不提供电话客服，也没有企业微信、个人微信、QQ 客服号。任何以「米兰数码商城客服」名义要求转账、扫码付款、提供验证码或银行卡密码的，均不是官方行为。

在线人工客服入口在非服务时间会转为留言模式，留言后按提交顺序回复。

## 人工服务 · 需要人工介入的典型场景

**常见问法**：什么情况要找人工 / 机器人解决不了怎么办 / 我要投诉 / 售后纠纷找谁

**答案**：以下场景建议直接转在线人工客服：

- 物流异常核查：显示签收未收到、超过 72 小时无轨迹、包裹破损少件
- 退款异常：审核通过超过 7 个工作日未到账、退款失败需更换收款方式
- 售后争议：对质量判定结果、退款金额有异议
- 发票问题：增值税专用发票申请、发票红冲与重开
- 投诉与建议：服务态度、配送体验、商品描述不符

在线客服工作时间为每日 9:00 至 21:00，也可发送邮件至 support@milan-digital.example.com。智能客服无法转接、无法创建工单、无法直接联系人工，需要你自行在上述入口发起。

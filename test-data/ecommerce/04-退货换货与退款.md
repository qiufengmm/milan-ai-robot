# 米兰数码商城 · 退货、换货与退款知识库

本文件为演示数据。文中退换货期限、运费承担与退款时效均为虚构，仅用于知识库检索演示。客服系统未接入订单与售后接口，无法提交退货申请、无法办理退款。

---

## 退货 · 七天无理由退货总体规则

**常见问法**：可以退货吗 / 不想要了能退吗 / 七天无理由是什么意思 / 签收后几天内能退

**答案**：符合条件的商品支持七天无理由退货，规则如下：

- 时间：自签收次日起 7 个自然日内提交申请，超期不再受理无理由退货。
- 商品状态：商品本体、包装、配件、赠品、说明书齐全，无使用痕迹、无划痕、无进液，不影响二次销售。
- 运费：非质量问题的无理由退货，寄回运费由买家承担；下单时支付的运费不退还。
- 申请入口：在「我的订单」中选择对应商品提交退货申请，客服无法代为提交。

无理由退货是「可以退」而不是「无条件退」，商品状态不满足上述条件时，商城可以拒绝。

## 退货 · 拆开包装还能不能退

**常见问法**：拆开包装还能退吗 / 拆封了能退吗 / 试用过能退吗 / 耳机拆了能退吗

**答案**：拆封后能否退货要按品类区分：

- 耳机类（AirBuds Pro 2、StudioMax 70、LiteBuds S）：因涉及个人卫生，仅拆开外包装、耳机本体未佩戴使用且耳帽未拆封的，可以申请无理由退货；已佩戴使用过的，非质量问题不支持无理由退货，质量问题按保修或换货处理。
- 键盘、鼠标、充电器类：拆封后可以退，但需无使用痕迹、无油污划痕、配件齐全、包装完整；已装机长期使用或键帽磨损的不支持。
- 定制刻字商品、商品页标注「不支持七天无理由」的清仓特价商品：拆封与否均不支持无理由退货。

是否属于「已使用」由售后收货检验判定，不以买家描述为唯一依据。

---

## 退货 · 哪些商品不支持无理由退货

**常见问法**：什么不能退 / 特价商品能退吗 / 刻字的能退吗 / 秒杀款能退吗

**答案**：以下情况不支持七天无理由退货：

- 定制刻字、定制配色的商品
- 商品页明确标注「不支持七天无理由退货」的秒杀、清仓、临期特价商品
- 已佩戴使用过的入耳式耳机
- 人为损坏、进液、私自拆修、擅自改装过的商品
- 缺少主要配件、赠品或包装导致无法二次销售的商品

以上商品出现质量问题时，仍按保修或换货政策处理，不受无理由退货限制。

## 退货 · 质量问题退货

**常见问法**：有质量问题怎么退 / 用了几天坏了能退吗 / 质量问题的运费谁出 / 收到就是坏的

**答案**：质量问题退货规则：

- 时限：自签收次日起 7 个自然日内可申请退货，15 个自然日内可申请换货；超过 15 天按保修政策维修处理。
- 判定：需提供故障现象说明，必要时提供照片或视频；售后收货检验确认属于质量问题的，认定为质量问题。
- 运费：确认质量问题后，往返运费由商城承担，先行垫付的寄回运费在退款时一并返还。
- 权益：质量问题退货不受「是否拆封」「是否使用过」限制。

是否属于质量问题以售后检验结果为准，人为损坏、进液、摔碰不属于质量问题。

---

## 换货 · 换货规则

**常见问法**：能换一个吗 / 换货怎么弄 / 颜色不喜欢能换吗 / 换货要多久

**答案**：换货规则：

- 质量问题：签收次日起 15 个自然日内可申请换货，换同型号同规格商品，往返运费由商城承担。
- 非质量问题（不喜欢颜色、买错型号）：不提供换货，可按无理由退货规则退货后重新下单。
- 同型号无库存：可改为退货退款，或等待补货后换发，等待时间以商品页补货说明为准。
- 换货时效：售后收到寄回商品并检验通过后，2 个工作日内发出新商品。

换货申请需在「我的订单」中提交，客服无法直接创建换货单。

## 退款 · 退款流程与到账时效

**常见问法**：退款多久到账 / 钱什么时候退回来 / 退款流程是什么 / 退到哪里

**答案**：退款流程与时效：

- 流程：提交申请 → 售后审核（1 至 2 个工作日）→ 寄回商品 → 收货检验 → 发起退款。
- 到账时效：审核通过后原路退回，微信、支付宝一般 1 至 3 个工作日到账，银行卡一般 3 至 7 个工作日到账。
- 退款路径：退回原支付账户，不支持退到其他账户、不支持退成余额或优惠券。
- 无需寄回的商品（如仅补发配件、协商部分退款）：审核通过后直接发起退款。

退款由售后系统发起，客服无法手动加急，也无法查询退款单的实时状态。

## 退款 · 退货运费由谁承担

**常见问法**：退货运费谁出 / 退货要自己付邮费吗 / 运费能退吗 / 有运费险吗

**答案**：退货运费承担规则：

- 质量问题、发错货、少件破损：往返运费由商城承担，买家先行垫付的寄回运费在退款时一并返还。
- 非质量问题的无理由退货：寄回运费由买家承担，标准为 8 元，偏远地区 15 元。
- 下单时支付的运费：无理由退货不退还；质量问题退货可随商品金额一并退还。
- 商城未提供运费险服务。

寄回时请使用可查询轨迹的快递，运费以实际支付凭证为准。

## 退款 · 退款金额如何计算

**常见问法**：能退多少钱 / 用了优惠券怎么退 / 部分退款怎么算 / 分期订单怎么退

**答案**：退款金额计算规则：

- 单件商品整单退货：退回该商品实付金额，即商品原价扣除优惠券分摊后的金额。
- 多件订单只退其中一件：按该商品分摊后的实付金额退款，优惠券不退回，剩余商品不重新计算优惠。
- 质量问题退货：实付金额加买家垫付的寄回运费一并退回。
- 无理由退货：只退商品实付金额，下单运费与寄回运费均不退。
- 分期订单：按原路退回，已产生的分期手续费是否退还需以支付平台账单为准。

最终退款金额以售后系统核算结果为准。

## 退款 · 退款迟迟未到账

**常见问法**：退款没到 / 说退了但没收到钱 / 退款失败怎么办 / 退款到哪了

**答案**：

- 审核通过后超过 7 个工作日仍未到账：先检查原支付账户的账单与银行卡流水，部分银行入账存在延迟。
- 仍无记录：通过在线人工客服提供订单号与退款申请时间，由人工核查退款单状态。
- 退款失败常见原因：原支付账户已注销、银行卡已挂失、支付渠道账户异常，需重新提供收款方式后由人工处理。

客服系统未接入退款查询接口，无法直接读取退款单状态，也无法手动重新发起退款。

---

## 退货 · 多件订单只退其中一件

**常见问法**：一单买了好几件能只退一件吗 / 部分退货可以吗 / 剩下的还能用券吗

**答案**：

- 支持部分退货：在「我的订单」中选择需要退的商品逐件提交申请。
- 退款金额按该商品分摊后的实付金额计算。
- 优惠券不退回，剩余商品不重新计算优惠，也不补差价。
- 赠品随主商品退回：赠品对应的主商品退货时，赠品需一并寄回，赠品缺失会从退款中扣除相应金额。

部分退货的寄回运费按一次寄回计算，不按件叠加。

---

## 退货 · 已发货或运输中能否拒收

**常见问法**：不想要了能拒收吗 / 快递到了不签收行吗 / 运输中能拦截吗

**答案**：

- 包裹在运输途中：商城无法拦截，需由收件人联系承运商说明拒收。
- 派送时拒收：可当场拒收并告知快递员原因，包裹退回仓库后按退货流程处理。
- 拒收产生的运费：无理由拒收的运费由买家承担；因破损、错发而拒收的运费由商城承担。
- 拒收后仍需在「我的订单」中提交退货申请，否则退款无法发起。

客服无法代为联系承运商拦截包裹，也无法直接触发退款。

# 米兰数码商城 · 退换货与退款补充问答

本文件为演示数据补充。退换货期限、运费和退款规则均为虚构；客服系统未接入售后操作接口。

---

## 退货 · 七天从何时开始及商品状态

**常见问法**：签收当天算第一天吗 / 第七天还能申请吗 / 无理由退货要保持什么状态

**答案**：七天无理由期限从签收次日起按自然日计算，在第 7 个自然日内提交申请。商品本体、配件、赠品、包装和说明书应齐全，无使用痕迹、划痕或进液且不影响二次销售；是否符合条件由售后检验。

## 退货 · 不同品类拆封后的处理

**常见问法**：键盘拆封还能退吗 / 耳机开盒没戴过能退吗 / 鼠标用过几天能无理由退吗

**答案**：耳机仅拆外包装且未佩戴、耳帽未拆封时可申请无理由退货；已佩戴的耳机非质量问题不支持。键盘、鼠标和充电器拆封后需无使用痕迹、配件齐全、包装完整；长期使用、磨损或进液不符合无理由退货条件。

## 退货 · 特价、定制商品与质量问题的区别

**常见问法**：清仓商品不能退吗 / 刻字键盘坏了能售后吗 / 秒杀商品有质量问题怎么办

**答案**：定制刻字或商品页标注“不支持七天无理由”的清仓、秒杀商品，不支持无理由退货；但出现质量问题仍可按质量售后规则处理。人为损坏、进液、私拆或缺少主要配件不属于无理由退货条件，最终按检验结果判断。

## 售后 · 质量问题退货与换货申请期限

**常见问法**：收到就是坏的几天内能退 / 用了十天坏了能换吗 / 质量问题要拍视频吗

**答案**：质量问题可在签收次日起 7 个自然日内申请退货，15 个自然日内申请换货；应说明故障现象，必要时提供照片或视频。售后检验确认质量问题后，往返运费由商城承担；超过 15 天按保修规则处理。

## 退款 · 无理由退货和质量退货的运费差别

**常见问法**：退货邮费谁承担 / 不想要了运费退吗 / 质量问题要我垫付吗

**答案**：无理由退货的寄回运费由买家承担，标准为 8 元、偏远地区 15 元，原下单运费不退，商城不提供运费险。确认质量问题、发错货或少件破损后，往返运费由商城承担；先垫付的寄回运费可凭实际支付凭证在退款时返还。

## 退款 · 多件订单部分退货的退款金额

**常见问法**：只退一件优惠券退吗 / 赠品要不要一起寄 / 剩下的商品会重新算价吗

**答案**：部分退货按该商品分摊后的实付金额退款，优惠券不退回，剩余商品不重新计算优惠也不补差价。若赠品对应的主商品退货，赠品需一并寄回；赠品缺失时可能从退款中扣除相应金额，最终金额以售后系统核算为准。

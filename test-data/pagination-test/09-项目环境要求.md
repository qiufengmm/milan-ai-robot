## 问题1：运行项目需要什么环境？

后端需要 JDK 21 与 Maven 3.9+，数据库使用 MySQL 8.x 或 PostgreSQL 15+，缓存使用 Redis 7.x。

---

## 问题2：前端需要什么版本？

Node.js 18 LTS 及以上，包管理器推荐 pnpm，浏览器建议 Chrome 110+。

---

## 问题3：需要几核服务器才够跑？

本地开发 4 核 8G 足够；若要在云服务器上完整部署，建议 2 核 4G 起步并预留 20G 磁盘。

---

## 问题4：可以用 Windows 开发吗？

可以，但涉及 Docker 与脚本的部分建议在 WSL2 下执行，避免路径与换行符问题。

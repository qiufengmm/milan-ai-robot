# 演示指引：VPN 远程接入

> 虚构演示资料，不代表任何真实企业制度。资料编号 IT-02，版本 1。

## 接入前提
- 仅使用公司发放并完成磁盘加密的设备连接公司 VPN；首次使用需在设备门户完成登记。
- 从公司软件门户安装「Milan Secure Access」客户端，不从搜索引擎下载同名软件。
- 使用公司账号与 MFA 验证；不要把验证码或恢复码转发给他人。

## 连接步骤
1. 打开客户端并选择配置「员工远程接入」。
2. 输入公司账号，通过 MFA 确认登录。
3. 状态显示「已连接」后访问内部系统；结束工作后主动断开连接。

## 排障
- 一直显示正在连接：先检查设备时间自动同步，再切换到可信网络重连一次。
- MFA 连续失败或账号锁定：停止尝试，使用内部账号自助流程或联系 IT 服务台。
- 公共 Wi-Fi 下工作前先连接 VPN；不要关闭证书校验或安装自签名证书。
- 本机器人不能远程更改 VPN 策略、解锁账号或代连设备。

# 演示指引：软件安装与更新

> 虚构演示资料，不代表任何真实企业制度。资料编号 IT-05，版本 1。

## 安装来源
- 公司批准的软件从「企业软件门户」安装；员工按岗位权限申请许可证。
- 禁止使用个人网盘、破解网站或来源不明的安装包安装办公软件。
- 管理员权限安装或驱动更新由 IT 服务台处理，员工不要绕过终端防护策略。

## 更新步骤
- 保存工作并连接稳定网络，在企业软件门户检查更新；更新过程中不要强制关机。
- 更新失败时记录软件名称、版本、错误代码和发生时间，然后提交 IT 服务单。
- 需要紧急回退时联系 IT；不要自行从旧版本网站下载安装程序。

## 许可证与兼容
- 软件许可证绑定公司账号或设备；更换设备前联系 IT 释放旧设备授权。
- 未列在企业软件门户中的工具需要主管说明业务用途并提交安全评估。
- 本机器人不判断具体软件是否已获批，不承诺许可证即时发放。

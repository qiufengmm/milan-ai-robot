# 简历描述草稿：企业内部知识问答机器人

技术栈：Java 21、Spring Boot 4.1、Spring AI 2.0、MyBatis-Plus、PostgreSQL / pgvector、Elasticsearch / IK、RRF、百炼 qwen3-rerank、SSE、Vue 3。

- **用户认证与知识库权限：** 基于 Spring Security Session、BCrypt 与 CSRF 实现账号登录；管理员创建或停用账号，按知识库授予 READER / EDITOR 权限；会话、资料、检索和反馈请求始终校验账号状态、本人归属及库授权。
- **企业资料管理与版本发布：** 通过分片续传、异步解析和 PG / ES 索引同步管理企业资料，为逻辑文档区分草稿、当前版及历史版；维护者预览片段并发布、撤回或替换版本，新问题仅检索当前发布文件，文件操作必须显式携带已授权库 ID。
- **混合检索与可追溯回答：** 组合 pgvector 语义召回、Elasticsearch BM25、RRF 与 Rerank；按当前发布文件预过滤候选，以 0.50 分数线过滤低相关片段，通过 SSE 返回实际来源文档、版本和片段，持久化完成、失败和取消状态。
- **连续问答与反馈处理：** 会话固定员工与知识库，使用最近最多 6 组完整问答、12,000 字符历史理解追问，每轮重新检索；改写失败时使用确定性回退。员工可反馈自己的回答，由对应库维护者核对来源、更新发布资料并记录处理结果。运行配置统一，无需按业务选择 profile。

**历史评测（清理前版本，虚构小规模语料）：** 2026-11-15 19:29–19:35 使用 `qwen3.8-flash`、温度 `0.0` 运行 60 个用例、64 个聊天轮次及 4 个权限请求。56/56 聊天用例收到非空完整回答，权限 4/4；人工判分为检索 54/55、答案 53/55、来源支持 52/52。VER03 因草稿前置状态不成立未计分，3 个纯澄清题不计来源支持。全量 3 次追问改写触发回退，此前 6 题门槛另有 2 次；全量没有回答生成或 TLS 失败。原始记录和计分边界见 [历史全量报告](eval/eval_report.md)。

**已知不足与边界：** 20:13 的 8 题、12 轮 [定向复测](eval/issues_retest_report_20261115_201353.md) 独立于上述 60 题成绩：CL01 仍未先确认假种，SAFE05 仍缺少明确拒绝远程操作及防护提醒；4 组多轮追问触发改写回退，部分回答存在来源外推断。VER03 实际草稿隔离通过且发布状态已恢复。清理没有据此宣称修复问答质量或历史超时；这些结果不代表生产准确率。助手未接入 OA、账号重置或工单系统，只解释资料中的流程，不能执行审批或 IT 操作。
